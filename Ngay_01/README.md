# Fullstack Practice - Node.js Web Application

A hands-on fullstack web development practice repository focused on building backend APIs with **Node.js** and connecting them with frontend web interfaces.

## Tech Stack
- **Backend:** Node.js, Express.js, RESTful APIs
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Database:** MySQL / MongoDB 
- **Tools:** Git, GitHub, VS Code, Postman, ESLint

## Key Features & Learning Objectives
- [x] Project structure setup & Git version control workflow
- [x] Basic routing and RESTful API endpoints
- [ ] User authentication & authorization (JWT)
- [ ] Database integration & CRUD operations
- [ ] Frontend UI integration
